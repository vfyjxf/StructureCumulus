# P2 skeleton — written blind from `08`, `11`, `20`, `23` only

Sources read before writing this file: `docs/spec/08-claims.md`, `docs/spec/11-engine.md`,
`docs/spec/20-execution-and-sections.md`, `docs/spec/23-claim-entry.md`. No `src/` file was read.
(One inventory command was run first and returned the *file names* under `kernel/claim` and
`kernel/engine`; no contents. That is disclosed because it mildly informs nothing here — every type
below is derived from a doc quote, not from a name.)

Conventions: `throw new UnsupportedOperationException()` for every body, including accessors
generated by records (records get their implicit accessors; only the extra methods below are stubbed).
`//` markers say what the doc does and does not give.
